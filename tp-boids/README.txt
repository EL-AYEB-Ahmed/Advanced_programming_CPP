This labwork is about artificial life, and more specially the study of crouds of agents. Let us focus on bird flocks, more nicely called bird “murmuration”, mainly observed with starlings.

This is an example https://www.youtube.com/watch?v=7-Ott8SFa5o&t=7s

The idea here is to model such behaviours in 2D, modelling a collection of agents and displaying the crowd behavior resulting from their interaction.

This labwork adresses basic C++ concepts:

    handle data structure, with methods
    manipulate arrays of data.
    use standard complex numbers
    getting ready for inheritance and virtual methods.
    …

You will produce videos… and all the groups/individuals will be challenged for making the best one. The winner price is an all-inclusive programming week-end with the C++ teacher you like the most.

You can inspire from the definition of “boids” : https://en.wikipedia.org/wiki/Boids
