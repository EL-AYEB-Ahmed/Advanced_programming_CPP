Advanced Programming C++

This repository contains my C++ self-studies and in-class labworks at CentraleSupélec.

C++ requires a precise understanding of what happens behind the language, especially how variables and objects are constructed and handled. In the self-study section, I explore these concepts by studying variable construction through the num type implemented in num.hpp.

I then apply these concepts in practice through different labworks, progressively developing my understanding of C++ Object Oriented programming.
